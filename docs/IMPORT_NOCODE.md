# Импорт ассистентов без кода

Сначала соберите версии с подставленными данными: `python tools/build_docx.py`. Готовые файлы появятся в `build/rendered/`:

- `build/rendered/prompts/<id>.md` — текст для поля инструкций;
- `build/rendered/knowledge/<id>/*.md` — файлы базы знаний для загрузки.

Без Python можно взять тексты прямо из Word-документа: промпт — из раздела «Системный промпт», базу знаний — из разделов FAQ, «Типовые обращения» и «Скрипты».

## ChatGPT — Custom GPTs
1. Explore GPTs → Create → вкладка Configure.
2. **Name:** «Лоцман — консультант по яхтам» (Боцман, Штурман — по аналогии). **Description:** цель из паспорта.
3. **Instructions:** весь текст из `build/rendered/prompts/<id>.md` (до 8 000 знаков — проверено сборщиком).
4. **Conversation starters:** четыре фразы из `config/assistants.yaml`.
5. **Knowledge:** загрузите все файлы из `build/rendered/knowledge/<id>/`.
6. **Capabilities:** веб-поиск, генерацию изображений и Code Interpreter — выключить. Ассистент должен опираться только на базу знаний.
7. Проверьте на 3–4 кейсах из `tests/cases/<id>.yaml` в окне Preview.

## Яндекс AI Studio
1. «Создать агента» → имя, модель (YandexGPT 5 Lite или Pro).
2. Инструкция — текст промпта. Температура — из паспорта (0.3–0.4).
3. Инструменты → поиск по файлам: создайте индекс из файлов базы знаний.
4. Тест в окне чата.

## SMAIPL
1. Создайте базу знаний и загрузите файлы `knowledge/<id>/*.md` (урок SMPb 02).
2. Создайте AI-агента, вставьте промпт, подключите базу знаний.
3. Выведите агента в Telegram (урок SMPb 03).

## Что работает иначе без кода
- Инструментов `create_handoff`, `get_interview_slots`, `book_interview` нет. Ассистент выводит текстовую карточку передачи, а слоты интервью берёт из базы знаний. Это предусмотрено промптами.
- Карточки никуда не отправляются автоматически. В демо это нормально, для работы — этап 2 из `CLAUDE.md` или сценарий n8n.
