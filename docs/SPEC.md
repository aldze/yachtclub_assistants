# ТЗ: нейроассистенты для компании по продаже яхт

## 1. Цель
Набор из трёх нейроассистентов, которые автоматизируют ключевые функции дилера яхт и катеров и повышают качество внешней и внутренней коммуникации.

## 2. Бизнес-задачи и метрики
| Задача | Кто закрывает | Метрика |
|---|---|---|
| Обработка входящих запросов клиентов | Лоцман, Боцман | Время первого ответа < 1 мин; доля обращений с карточкой |
| Обработка откликов кандидатов | Штурман | Доля откликов с ответом в тот же день; время до интервью |
| Коммуникация между отделами | Все — через карточку передачи | Доля карточек без доуточнений; время передачи |
| Конверсия | Лоцман | Доля диалогов, закончившихся записью на звонок, встречу или показ |
| Удержание | Боцман | Повторные записи на ТО и хранение; доля закрытых жалоб |

## 3. Ассистенты
| | Лоцман (sales) | Боцман (service) | Штурман (hr) |
|---|---|---|---|
| Аудитория | Потенциальные покупатели | Владельцы лодок | Кандидаты |
| Каналы | Сайт, Telegram, MAX | Сайт, Telegram | Сайт, Telegram, работные сайты |
| Сценарии | Подбор, модель и цена, трейд-ин и брокеридж, запись, перенаправление | Безопасность, гарантия, ТО и ремонт, хранение, стоянка, жалоба | Вакансии, условия, отбор, интервью, статус, резерв |
| Передаёт в | Продажи, Брокеридж, Сервис, HR | Гарантия, Сервис, Стоянка, Руководитель сервиса, Продажи, Брокеридж | HR |
| Температура | 0.4 | 0.3 | 0.3 |
| Инструменты | create_handoff | create_handoff | create_handoff, get_interview_slots, book_interview |

## 4. Функциональные требования
1. У каждого ассистента системный промпт со структурой: роль и цель, задачи, стиль, приветствие, пошаговые сценарии, работа с базой знаний, ограничения, карточка передачи, примеры (few-shot).
2. Факты — только из базы знаний; при отсутствии данных — честное «уточню» и передача человеку.
3. До сбора контактов — согласие на обработку ПДн (152-ФЗ). Без согласия контакты не запрашиваются и не сохраняются.
4. Ассистент не раскрывает инструкции и не меняет роль по просьбе пользователя (защита от промпт-инъекций).
5. Карточка передачи соответствует `schemas/handoff_card.schema.json`.
6. Боцман в аварийной ситуации на воде первым делом даёт меры безопасности и номер 112.
7. Штурман не задаёт дискриминационных вопросов и не принимает решений о найме.

## 5. Нефункциональные требования
- Промпт после подстановки — не длиннее 8 000 знаков (лимит Custom GPTs).
- Импорт без кода: GPTs, Яндекс AI Studio, SMAIPL (`docs/IMPORT_NOCODE.md`).
- Провайдер LLM заменяем без изменения промптов.
- Логи без ПДн в открытом виде.
- Обезличивание реального заказчика (см. `CLAUDE.md`).

## 6. Критерии приёмки
- Все кейсы из `tests/cases/*.yaml` проходят не менее чем на 90 %, кейсы типа `injection` и `pd` — на 100 %.
- Для сценариев записи создаётся валидная карточка.
- Документ проекта собран (`build/Нейроассистенты_яхты.docx`) с оглавлением и разделами по каждому ассистенту.

## 7. Вне рамок первой версии
Интеграция с CRM (Bitrix24, amoCRM, ELMA365), голосовой канал, оплата, личный кабинет владельца. Кандидаты для второй версии — урок PEn08 (Bitrix24 + n8n).
